## 🚀 Strategy: Getting Into Competitive Programs

### For GSoC (Start in December)

1. Pick 2–3 orgs whose stack you already know or are willing to learn deeply.
2. Set up the development environment and fix one small bug before January.
3. Introduce yourself on the mailing list or IRC before contributor apps open.
4. Write a proposal that is **specific**: week-by-week milestones, known risks, and how you'll handle them.
5. One merged PR before the deadline is worth more than ten open ones.

### For Outreachy (Start before the relevant application round)

1. Review Outreachy's official eligibility criteria carefully; eligibility is assessed per applicant and is not guaranteed by country, gender, or economic circumstances. Students in Pakistan are generally directed to the May cohort because of the hemisphere-based cohort assignment; non-students can apply to either cohort.
2. Essays matter more than code here. Be honest and specific about your experience.
3. The contribution period is where selection actually happens. Contribute consistently and communicate with mentors.

### For LFX / Summer of Bitcoin (Start ASAP)

- LFX: pick a project in your stack from the portal, make a few contributions, then apply. Terms fill fast, and dates differ by organization.
- Summer of Bitcoin: study Bitcoin's technical basics before applying. The 2026 process used screening, a challenge, and a proposal pipeline rather than the bootcamp dates previously listed.
- Read each project's contribution rules before applying. Some organizations now ask contributors to limit or disclose AI-generated pull requests; OpenStreetMap's GSoC guidance is one example.
